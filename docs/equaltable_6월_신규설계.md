# 📌 프로젝트 생성 분기 구조

```
Project 생성하기
       │
    ┌───────────────────────────────┐
ISO 14067                      환경성적표지
    │                               │
  ┌──────────┐             C2Grave(사용단계 제외) 고정
C2Gate     C2Grave                  │
             │                   ┌────────────┐
      ┌──────────────┐       신규 작성     C2Gate 연동
    신규 작성    C2Gate 연동               (ISO 14067 C2Gate만 연동 가능)
    (Option A)  (Option B)                (환경성적표지 EF로 재계산)
                (ISO 14067 EF)
```

### 방법론별 시스템 경계 제약

| 방법론 | C2Gate | C2Grave |
|---|---|---|
| ISO 14067 | 가능 | 가능 |
| 환경성적표지 | 불가 (비내구재 규정) | 고정 (사용단계 제외) |

### C2Gate 연동(Option B) 규칙

- 연동 가능 조건: ISO 14067 C2Gate 프로젝트 **확정 완료** 상태만 허용
- 연동 시 가져오는 것: 탄소발자국 계산 결과값 ❌ / **투입물·산출물 리스트** ✅
- 출고량(Y kg RC) 입력 → 전 투입물에 비율(Y ÷ X) 자동 반영
- 환경성적표지에서 연동 시: ISO 14067 EF → **환경성적표지 EF로 재계산** (국내 DB 우선 원칙)
- 기준년도 불일치 시: 경고 표시 후 허용

### C2Grave 프로젝트 단위

- 납품처 1곳 = C2Grave 프로젝트 1개
- C2Gate는 시설 단위기간 평균 원단위 기준 확정값 공유
- C2Grave는 납품처별 출고량·수송·폐기가 상이하여 납품처마다 별도 산출 (환경성적표지는 사용단계 미포함)

## 2. 조건부 렌더링 규칙

```
[Section 1 — 생성 시]

방법론 = 환경성적표지
  → 시스템 경계: C2Grave 고정 표시, 선택 UI 비활성화
  → 작성 방식: Option A / Option B 표시
  → Option B: ISO 14067 C2Gate 확정 프로젝트 목록만 표시
               + "투입물 리스트 연동 후 환경성적표지 EF로 재계산됩니다" 안내 표시

방법론 = ISO 14067, 시스템 경계 = C2Gate
  → 작성 방식 섹션 비표시
  → Section 4 사용단계 시나리오 비표시

방법론 = ISO 14067, 시스템 경계 = C2Grave
  → 작성 방식: Option A / Option B 표시
  → Section 4 사용단계 시나리오 표시

Option B 선택
  → 출고량(Y kg RC) 입력 필드 표시
  → 연동 프로젝트 기준년도 ≠ 현재 기준년도 → 경고 표시, 진행 허용

Section 4 사용단계 시나리오 = 드립
  → 여과지: 투입물·산출물 관리 단계 자동 포함 플래그 설정

[Section 1 — 생성 후 방법론 변경]

C2Grave 프로젝트에 한해 방법론 교체 허용 (ISO ↔ 환경성적표지)
  → C2Gate 프로젝트에서 방법론 변경 차단
  → 시스템 경계 변경 불가

방법론 변경 시 포장재 분류 처리
  → ISO → 환경성적표지:
       키워드 DB 기반 자동 매핑 (최소포장재 / 출하포장재)
       + 사용자 확인 UI ("매핑 결과를 확인하세요")
       + 미분류 항목은 수동 지정
  → 환경성적표지 → ISO:
       최소포장재 + 출하포장재 → 전체 "포장재"로 자동 병합

방법론 변경 시 누적질량기여도
  → 출하포장재 추가(ISO→환경성적표지) 또는 제거(환경성적표지→ISO) 시: 재분석 트리거
  → 그 외 단순 교체: 재분석 불필요
```

## 배출량 산식

```
사용단계 배출량 (kg CO₂e/kg RC)
  = (분쇄 전력 원단위 + 추출 전력 원단위) × 전력 EF (kg CO₂e/kWh)
```

- 적용 전력 EF: 한국 계통 평균 EF (EG-TIPS 기준년도 값)

## Section 2 — 폐기물 처리 방식

### MRV 트랙

| 항목 | 입력방식 | 타입 | 필수 | 비고 |
| --- | --- | --- | --- | --- |
| 재활용 위탁처리 증빙서류 선택 | [직접-OCR풀] | File | 선택 | 선택 시 해당 중량만큼 재활용 증빙분으로 처리 |
| 재활용 처리 폐기물 종류 | [OCR] | Select | 조건부필수 | 증빙 선택 시 필수 |
| 재활용 처리 중량 | [OCR] | Decimal (kg) | 조건부필수 | 증빙 선택 시 필수. **품목별** 발생량 초과 불가. 초과 시 발생량 상한 자동 적용. 타 품목 이월 불가 |
| 잔여량 처리 비율 | [자동] | Decimal (%) | — | 국가 통계 자동 적용 |
- OCR 대상문서: 재활용폐기물처리 증빙서류 (#15)
    - 재활용 처리 폐기물 종류: 재활용폐기물처리 증빙서류 (#15)
    - 재활용 처리 중량: 재활용폐기물처리 증빙서류 (#15)

**처리 구조:**

- 재활용 증빙 제출 시:
    - 품목별 독립 처리. 타 품목 초과분 이월 불가
    - 증빙 중량 ≤ 발생량: 증빙 중량 전량 재활용 인정
    - 증빙 중량 > 발생량: 발생량까지만 재활용 인정. 초과분 무시
    - 재활용 인정량 → 수송 EF만 반영. 처리 EF = 0
    - 잔여량 → 국가 통계 비율 적용
- 증빙 미제출 시: 전량 국가 통계 비율 자동 적용

**시스템 처리 원칙:**

- 재활용 증빙서류 내 품목 미명시 시: 해당 증빙 무효 처리
- 품목별 발생량 초과분: 자동으로 발생량 상한 적용. 사용자에게 경고 표시
- 초과분의 타 품목 이월: 불가

### 계산기 트랙

- 전량 국가 통계 비율 자동 적용. 사용자 입력 없음.

## 배출량 산식

### 재활용 증빙분 (MRV 트랙)

```
수송 배출량 = 증빙 중량(kg) × 재활용시설까지 거리(km) × 트럭 EF ÷ 1,000
              (⑨ 폐기단계-수송에서 산출된 재활용시설 거리 자동 연결)
처리 배출량 = 0
```

### 잔여량 (증빙 제출 후 잔여 또는 전량 일반폐기물)

```
처리 배출량
  = Σ(잔여량 × 처리방식별 비율 × 처리방식별 EF)

처리방식: 소각 / 매립 / 재활용
비율: 전국 폐기물 발생 및 처리현황 통계 기준
```

## 보고서 가정사항 자동 기재

**전 트랙 공통:**

> "폐기물 처리 배출량은 전국 폐기물 발생 및 처리현황 통계 기준 소각·매립·재활용 비율을 적용하여 산정함. 재활용 위탁처리 증빙 제출 시 해당 중량은 재활용시설 수송 배출량만 반영하며 처리 공정 환경영향은 산정 범위에서 제외함. 잔여량은 통계 비율에 따라 처리방식별 EF를 적용하여 산정함."
> 

**환경성적표지 트랙 추가 기재:**

> "환경성적표지 방법론의 경우 폐기물 수송은 산정 범위에 포함되지 않음. 폐기물 처리 배출량만 산정함."
>

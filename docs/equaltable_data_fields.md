# Equaltable 화면 데이터 항목 정의서

> 작성 기준: 2026년 7월 28일
> 목적: 개발자 전달용 UI 입력 항목 정의 (개발 구현 참조용 독립 완결 문서)
> 기준 문서: equaltable_6월_신규설계.md / equaltable_6월_설계변경사항.md
> 기능단위: 로스팅된 커피 N kg (시설 단위 기간 평균 원단위) — N은 사용자 입력. 내부 산정 1kg 고정. 결과 표시 시 N 배율 적용.
> 현재 버전: v2.0.4
> 이전 버전: v2.0.3

## 입력방식 범례

| 기호 | 입력방식 | 설명 |
|---|---|---|
| [직접] | 직접입력 | 사용자 직접 입력 |
| [OCR] | OCR 자동추출 | OCR 추출값. 확정 후 변경 불가. 수정 이력 자동 기록 |
| [자동] | 시스템 자동계산 | 시스템 계산 결과. 수정 불가 |
| [연동] | 회원정보 연동 | 회원가입 등록값 자동 표시. 수정 불가 |
| [직접/자동-API] | 직접입력 또는 API 자동산출 | 기본: API 자동산출. 미산출 시 직접입력 전환 |
| [직접-OCR풀] | OCR 풀에서 선택 | 문서 업로드 풀에서 선택. OCR 추출값 자동 채움 |

**조건부 렌더링:**
```
방법론 = 환경성적표지
  → 시스템 경계: C2Grave 고정 표시. 선택 UI 비활성화
  → 작성 방식: Option A / Option B 표시
  → Option B: ISO 14067 C2Gate 확정 프로젝트 목록만 표시

방법론 = ISO 14067, 시스템 경계 = C2Gate
  → 작성 방식 비표시

방법론 = ISO 14067, 시스템 경계 = C2Grave
  → 작성 방식: Option A / Option B 표시

Option B 선택
  → 출고량 입력 필드 표시
  → 연동 프로젝트 기준년도 ≠ 현재 기준년도 → 경고 표시. 진행 허용
```

**방법론 생성 후 변경 규칙:**
```
C2Grave 프로젝트에 한해 ISO ↔ 환경성적표지 교체 허용
  → C2Gate 프로젝트 변경 차단
  → 시스템 경계 변경 불가

ISO → 환경성적표지 변경 시 포장재 처리:
  → 키워드 DB 기반 자동 매핑 (최소포장재 / 출하포장재)
  → 사용자 확인 UI ("매핑 결과를 확인하세요")
  → 미분류 항목 수동 지정

환경성적표지 → ISO 변경 시 포장재 처리:
  → 최소포장재 + 출하포장재 → 전체 "포장재"로 자동 병합

방법론 변경 시 누적질량기여도:
  → 출하포장재 추가(ISO→환경성적표지) 또는 제거(환경성적표지→ISO) 시: 재분석 트리거
  → 그 외 단순 교체: 재분석 불필요
```

# ADM 관리자 모듈 기능 도출

- 작성일: 2026.08.12
- 성격: 기존 정의(기능정의서·화면정의서 ADM 모듈) 정리 + 완결성 점검(갭 분석)
- 소스: equaltalbe_기능정의서.md, equaltalbe_화면정의서.md

---

## 1. 모듈 성격

- 관리자 사이트(별도 도메인·별도 배포) 전용
- 전 기능 admin 권한 필요, 일반 사용자(Manager/Member) 접근 불가
- Admin 계정: Super Admin 단일 권한, 하위 admin 권한 분리 없음
- 권한관리 별도화면 없음(사용자 상세 내 역할변경으로 충분, Manager/Member 2단계 고정)

---

## 2. 기존 정의 기능 목록 (15개)

### 2.1 인증

**ADM-AUTH-001 관리자 로그인**
- 관리자 사이트 접근용 별도 인증경로, 일반사용자 로그인과 완전분리
- 화면: /admin/login
- 예외: 일반계정 접근시도 거부
- 부가: 2단계인증(2FA) 미적용, 로그인 성공·실패 이력(일시·IP) 기록, 본인 접속이력 조회 가능

### 2.2 사용자 관리

**ADM-USER-001 사용자 목록 조회**
- 전체 테넌트 소속 사용자 계정 목록
- 화면: /admin/users
- 표시항목: 이름·이메일·소속조직·권한(Manager/Member)·가입일·계정상태·최근로그인일
- 필터: 소속조직·역할·상태(활성/정지/탈퇴)
- 예외: 0건시 빈 상태 안내

**ADM-USER-002 사용자 상세 조회·수정**
- 개별 사용자 정보 상세조회·수정
- 화면: /admin/users/:userId
- 기능: 역할변경(Manager↔Member), 계정 활성화·정지·탈퇴처리, 비밀번호 초기화(재설정링크 발송), 로그인이력(일시·IP·기기) 조회
- 예외: 권한변경 즉시반영

### 2.3 조직(테넌트) 관리

**ADM-TENANT-001 테넌트 목록 조회**
- 전체 기업(테넌트) 목록
- 화면: /admin/tenants
- 표시항목: 조직명·사업자등록번호·대표담당자·소속사용자수·프로젝트수·가입일·상태
- 비고: 신규조직은 회원가입시 사업자등록증 OCR 인식 후 admin 사전승인 없이 즉시 활성화. Admin은 사후 정지조치만 수행

**ADM-TENANT-002 테넌트 상세 조회·관리**
- 개별 테넌트 조직정보·소속사용자·프로젝트현황 조회, 상태변경
- 화면: /admin/tenants/:tenantId
- 기능: OCR추출 사업자정보(사업장명·사업자등록번호·주소) 조회, 소속사용자 목록(사용자상세 이동 가능), 조직상태 변경(활성→정지), 업로드문서 연결조회
- 하위탭: ADM-LOG-002(프로젝트 감사이력)

### 2.4 배출계수(EF) 관리

**ADM-EF-001 배출계수 목록 조회**
- EF DB 전체를 섹션별(원부자재·수송·제조단계·사용단계·폐기단계) 조회
- 화면: /admin/factors
- 표시항목: 항목명·값·단위·출처·적용표준·현재버전·최종갱신일·갱신자·DQI종합점수
- 필터: 표준(ISO/환경성적표지)·LCA단계·활성상태
- GWP표시: ISO소속=AR5원칙, 환경성적표지소속=SAR 준용 각각 표시
- 관리대상: 원부자재EF·수송EF·제조단계EF(전력·연료연소·환경성적표지에너지)·폐기단계처리EF
- 비고: 전력배출계수(EG-TIPS)는 연도별 행 관리, 동일연도 값 덮어쓰기 없이 신규연도 행만 추가. 에너지원별 계산값(전력EF·연료연소EF·NCV 조합)은 직접입력 불가, 기반항목 갱신시 자동재계산

**ADM-EF-002 배출계수 등록·수정**
- 신규 등록 또는 기존값 수정(수정시 신규버전 저장, 이전버전 유지)
- 화면: /admin/factors (등록·수정 폼)
- 처리흐름: 값입력(값·단위·출처·적용시작일) → 확인모달(요약+적용시작일) → 등록확정 → "적용대기중" 저장(계산 미반영) → 적용시작일 도래시 자동 "현재버전" 전환, 기존버전은 이력이동
- 입력항목: 값·단위·출처(문헌·기관명·발행연도)·데이터품질평가 6항목(기술적·지리적·시간적 대표성·정밀성·완전성·일관성)·적용시작일
- 예외: 적용시작일 기본값=등록일+24시간(등록일 이전 불가), 유예기간중 등록취소 가능(취소이력 감사로그기록), 유예기간중 확정프로젝트는 기존버전 기준계산, 기발행보고서 스냅샷버전 변경불가
- 비고: 보고서발행시점 스냅샷 원칙에 따라 기발행 보고서 수치엔 영향없음. GWP처리방식은 ISO항목에 한해 참고정보 표시(수정불가, 고정값)

**ADM-EF-003 배출계수 버전 이력 조회**
- 특정 배출계수의 전체 버전이력(값변경내역·변경일·변경자·변경사유) 시계열조회
- 화면: /admin/factors/:factorId/history
- 기능: 특정 보고서 발행시점 적용버전 확인, 각 버전별 데이터품질평가 근거 조회
- 예외: 이력삭제 불가(감사목적), 레코드 직접수정 불가(신규버전 등록만 가능)

### 2.5 기준데이터 관리

**ADM-MASTER-001 기준 데이터 조회·관리**
- 시스템 전반 공통 기준데이터(국가폐기물통계비율·로스팅수율·커피박함수율·채프계수·생두문헌값·에너지원별NCV·가스단위환산계수·사용단계전력원단위 등) 조회·갱신
- 화면: /admin/master-data
- 처리흐름: ADM-EF-002와 동일(값입력→확인모달→적용대기중→자동전환)
- 예외: ADM-EF-002와 동일(24시간유예, 등록취소 가능)
- 비고: 연1회 이상 정기갱신 권장. 세트값 항목(폐기물처리비율 등)은 하위값 합계 100% 검증 병행

**ADM-MASTER-002 포장재 기준 데이터 관리**
- 사전정의 포장재 3종(알루미늄포일·증착필름·크라프트페이퍼)의 재질구성비율·재질별EF 관리
- 화면: /admin/master-data (포장재 섹션)
- 기준: 환경성적표지 출처
- 예외: 재질구성비율 합계 100% 미달시 저장불가

### 2.6 참조 데이터셋 관리

**ADM-REF-001 폐기물 처리시설 위치 DB 관리**
- 환경부 전국폐기물처리시설현황 DB 기반 시설명·주소·처리방식(소각/매립/재활용) 관리
- 화면: /admin/reference-data (폐기물처리시설 탭)
- 처리흐름: CSV/Excel 일괄업로드 또는 개별수동추가 → 확인모달(변경건수+적용시작일) → 등록확정 → "적용대기중" → 자동전환
- 예외: 24시간유예, 등록취소가능, 이전버전 스냅샷보관
- 비고: 폐기단계-수송 시군구기준 자동매핑의 기준점 데이터

**ADM-REF-002 물질 정규화 DB 관리**
- EF매칭알고리즘(Dual-Stage Matching) 기준 물질명 마스터데이터(표준물질명·별칭·연결EF카테고리) 관리
- 화면: /admin/reference-data (물질정규화 탭)
- 처리흐름·예외: ADM-REF-001과 동일

### 2.7 감사로그

**ADM-LOG-001 감사 로그 조회**
- Admin 자신의 조작이력 대상(배출계수·기준데이터·참조데이터셋 신규버전등록, 사용자상태·역할변경, 조직상태변경, 시스템설정변경, 고객업로드문서 원본열람)
- 화면: /admin/audit-logs
- 표시항목: 조작일시·조작자(admin계정)·조작유형·대상·변경전값·변경후값·사유
- 필터: 조작유형·조작자·기간
- 예외: 로그삭제 불가(영구보존), 조회전용
- 비고: 사용자의 프로젝트 내 행위(OCR수정 등)는 각 프로젝트 자체이력으로 별도관리(본 화면 대상 아님)

**ADM-LOG-002 프로젝트 감사 이력 조회**
- 특정 프로젝트의 전체 변경이력(입력값변경·OCR수정·확정·보고서발행 등) 조회
- 화면: 테넌트상세(/admin/tenants/:tenantId) 내 감사이력 탭
- 목적: 제3자 검증기관 대응, 내부감사
- 비고: OCR추출값 수기수정 이력은 별첨B 형태로 별도 다운로드 제공(AUD모듈 연동)

### 2.8 시스템

**ADM-SYS-001 시스템 운영 모니터링**
- OCR처리현황·API응답상태·에러로그 등 운영지표 확인(장애 조기감지)
- 화면: /admin/monitoring
- 비고: 문서 1건 처리 3초이내 성능목표치 모니터링 포함

**문서 열람** (별도 기능ID 없음, 화면정의서 규정)
- 조직상세·사용자상세 화면 내 접근(별도메뉴 없음)
- 평시: 문서목록(파일명·문서종류·업로드일·OCR처리상태)·OCR추출 구조화값 조회만 가능
- 원본이미지 열람: 예외적 기능. "원본"=PII마스킹(OCR-006) 완료 후 저장본(마스킹이전 이미지는 서버 미존재)
- 열람시 사유(OCR오류확인/기타) 선택·입력 필수, 즉시열람+감사로그자동기록+고객사 사후알림발송

**시스템 설정** (별도 기능ID 없음, 화면정의서 규정)
- 비밀번호 규칙(최소길이·복잡도) 설정
- 세션 만료시간 설정
- 범위제외: Feature flag·외부연동 API키 관리

## 4. 갭 분석 — 미정의 추가 검토 항목 (제안, 확정 아님)

기존 15개 기능을 카테고리(회원·조직·EF·기준데이터·감사로그 등) 기준 점검한 결과, 아래 3건은 기존 문서에 명시적 정의가 없어 검토 필요 항목으로 도출함.

**ADM-DASH-001 관리자 대시보드 (제안)**
- 필요성: 관리자 로그인 직후 진입화면 미정의. 랜딩화면 없이 /admin/users 등 개별화면으로 바로 진입하는 구조로 추정됨
- 제안범위: 전체 테넌트수·활성사용자수·진행중 프로젝트수, EF/기준데이터 "적용대기중" 건수(24시간유예 중인 항목 일괄확인), 최근 감사로그 요약
- 우선순위: 중(운영 편의성, 필수요건은 아님)

**ADM-NOTICE-001 공지사항 관리 (제안)**
- 필요성: CMN모듈 설명("회원가입·승인·로그인·권한·알림·대시보드")상 "알림" 존재하나, 이는 사용자측 수신기능으로 추정됨. Admin이 점검안내·정책변경 등을 등록해 전사용자에게 노출하는 발신기능은 별도 미정의
- 확인필요: CMN-알림 관련 기능정의(USER-XXX) 재확인 후 중복여부 판단 필요
- 우선순위: 중

**ADM-EXPORT-001 마스터데이터 백업·내보내기 (제안)**
- 필요성: EF DB·기준데이터·참조데이터셋 전체를 CSV/Excel로 일괄 export하는 기능 미정의(장애복구·이관·외부감사대응 목적)
- 우선순위: 하(MVP 이후 검토 가능)

## 5. 후속 조치 필요사항

- 3개 갭 항목 채택여부 판단
- 채택시 기능정의서 번호체계(ADM-DASH/NOTICE/EXPORT-XXX) 및 화면정의서 반영위치 확정
- CMN-알림 기능 기존정의와 ADM-NOTICE 중복여부 우선 확인 필요

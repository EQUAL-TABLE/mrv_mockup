## 📌 2. 제조전단계-원부자재

### Section A — 생두 정보

#### **A-1. 생두 탄소배출량**

- 생두 단위 탄소배출량: 직접입력 또는 기본값 1.165 kg CO₂e/kg 선택

#### **A-2. 생두 포장 정보**

- 포대 재질: 황마+PP,
- 포대중량 60kg(=포대 1자루에 생두 60kg)
- 포대 1ea 무게: 황마 1,000g / PP 300g
- 포대 수량 / 총 투입 질량: 자동 계산 (화면 표시)

#### **A-3. 생두 기본정보**

- 화면 노출 항목 없음 (전체 삭제)
- 생두 투입량: 내부 자동 계산값으로만 보유. 산식 = 생산량(kg) ÷ 0.7612. 화면 미표시, 배출량 계산 내부 참조용
- 생두 포장재 사용에 대한 탄소배출량은 산정하지 않음.

---

### Section D — 최소포장재

**D-1. 재질 정보**

- 재질 지정 방식: A(사전 정의 3종) 고정
- 포장재 종류: 직접입력 선택

```html
알루미늄 합지 포장재: 2.0960880713407752 kg CO₂e/kg
증착 삼중지 포장재 : 2.0852596610898624 kg CO₂e/kg
크라프트 삼중지 포장재 : 1.6378757679092296 kg CO₂e/kg
```

**D-2. 수량 및 질량**

- 1ea 무게 / 포장 단위 무게: 직접입력
- 단위 기간 사용량 / 총 사용 중량: 자동 계산

---

### Section F — 여과지 (조건부: 드립 + C2Grave만 표시)

- 재질 지정 방식: 크라프트지 고정
- 여과지 총 질량: 자동 계산, 수정 불가 (원두 14g에 대하여 여과지 1.6g짜리 1ea 사용)\

```html
크라프트지: 1.162558936139 kg CO₂e/kg
```

## 📌 3. 제조전단계-수송

### Section 1. 생두 수송 (단일 Leg 고정, 출발지·도착지 입력 없음)

**B-1. 수출국 내륙수송**

- 수송 거리: 직접입력 (필수)
- 수송수단: 트럭 고정
- 수송량: 자동 연결 (생두 투입량)

**B-2. 국제수송**

- 수송 거리: 직접입력 (필수)
- 수송수단: 직접입력 선택 (선박/항공)
- 수송량: 자동 연결 (생두 투입량)

**B-3. 수입국 내륙수송**

- 수송 거리: 직접입력 (필수)
- 수송수단: 트럭 고정
- 수송량: 자동 연결 (생두 투입량)

> 공통: API 거리 자동산출 미지원. 배출량은 결과 화면에서만 표시

## 📌 4. 제조단계

### Section A — 전력 (로스팅)

| 항목 | 입력방식 | 비고 |
| --- | --- | --- |
| 배치당 생두 투입량 | 직접입력 (필수) | 총 배치 수 산출 기준 |
| 총 배치 수 | 자동 계산 | 생두 투입량 ÷ 배치당 투입량, 소수점 올림 |
| 로스터기 소비전력 | 직접입력 (필수) | kW |
| 배치당 사용시간 | 직접입력 (필수) | 분 |
| 부하율 | 자동 고정 (70%) | 수정 불가 |
| 추정 전력 사용량 | 자동 계산 | 소비전력 × 부하율 × 사용시간 ÷ 60 × 총배치수 |

> Section B(재생에너지)는 MRV 전용, 계산기 트랙 섹션 자체 없음
> 

### Section C — 가스 (로스터기 연료유형 = 전력+가스 시만 표시)

| 항목 | 입력방식 | 비고 |
| --- | --- | --- |
| 가스 종류 | 직접입력 선택 | 천연가스 / LPG |
| 가스 사용량 | 직접입력 (필수) | 단위는 가스 종류에 따라 아래와 같이 자동 고정 (선택 UI 없음) |
| 단위 | 고정 | 천연가스: Nm³ / LPG: kg |
| 가스 배출량 | 자동 계산 | 사용량 × 고정 EF |

**고정 EF**

```html
- 천연가스: 2.1730228 kg CO₂e/Nm³ (환경성적표지 평가계수, 연료원별-LNG-제조업 및 건설)
- LPG: 1.864 kg CO₂e/kg (환경성적표지 평가계수, 연료원별-LPG-제조업 및 건설)
- 전기: 0.4951067159084 kg CO₂e/kwh (환경성적표지 평가계수, 원료 및 에너지 생산, 에너지, 전기)
```

### Section D — 채프 발생량

| 항목 | 입력방식 | 비고 |
| --- | --- | --- |
| 채프 발생량 | 자동 계산, 수정 불가 | 생두 투입량 × 0.006 (6g/kg GB, Bytof et al. 2024) |

## 📌 5. 사용단계

### 화면 목적

- ①프로젝트기본정보에서 선택한 사용단계 시나리오(드립/에스프레소/콜드브루) 기준 분쇄·추출 전력 사용량 및 배출량 자동 산출
- 사용자 입력 없음, 전량 자동 산출, 읽기전용

### 표시 항목 (전부 자동 계산)

| 항목 | 값/산식 | 비고 |
| --- | --- | --- |
| 분쇄 전력 원단위 | 0.019 kWh/kg RC (고정) | Páez et al.(2018) Table 3 |
| 추출 전력 원단위 | 시나리오별 고정값 | 드립 3.771 / 에스프레소 0.435 / 콜드브루 0 kWh/kg RC (Shadow PEFCR 2025) |
| 사용단계 배출량 | (분쇄원단위+추출원단위) × 전력 EF | 결과 화면에서만 표시 |

## 📌 6. 폐기단계-처리

### 대상 폐기물 (경계별)

| 경계 | 대상 |
| --- | --- |
| C2Gate | 생두 포장재, 채프 |
| C2Grave | 생두 포장재, 채프, 최소포장재, 커피박, 여과지(드립 시) |

### Section 1 — 폐기물 발생량 (읽기전용, 자동 누적)

| 폐기물 | 발생량 산식 |
| --- | --- |
| 생두 포장재 | 포대 수량 × 1ea 무게 ÷ 1,000 |
| 최소포장재 | 단위 기간 사용량(ea) × 1ea 무게 ÷ 1,000 |
| 커피박 | 단위 기간 원두 생산량(kg RC) × 2.50 |
| 여과지(드립) | 총 사용 중량 |
| 채프 | 생두 투입량(kg) × 0.006 |
- 계산기 트랙은 납품처(제품유통 화면) 자체가 없어 "발생 위치" 개념 불필요.
- 처리 배출량 산정에 거리·주소 정보 미사용

### Section 2 — 폐기물 처리 방식 (입력 항목 없음, 조회 전용)

전량 국가 통계 비율 자동 적용. 재활용 증빙 개념 없음.

**적용 폐기물 분류**: 계산기 트랙 대상 5종(생두포장재·최소포장재·커피박·여과지·채프) 전부 "종량제방식 혼합배출-가연성 → 생활폐기물" 단일 분류로 귀속 (최소포장재 3종 사전정의 재질도 복합재질로 간주되어 동일 분류)

**처리 비율 (환경부 전국 폐기물 발생 및 처리현황 2024)**

| 처리방식 | 비율 |
| --- | --- |
| 재활용 | 20.02% |
| 소각 | 63.72% |
| 매립 | 16.27% |

**처리방식별 EF (생활폐기물, 환경성적표지 평가계수 2021)**

| 처리방식 | EF (kg CO₂e/kg) |
| --- | --- |
| 매립 | 0.455146348309567 |
| 소각 | 1.18168730881208 |
| 재활용 | 0.0111671090092395 (※음식물폐기물 재활용 EF 준용) |

**배출량 산식**

```
처리 배출량 = Σ(발생량 × 처리방식별 비율 × 처리방식별 EF)
```

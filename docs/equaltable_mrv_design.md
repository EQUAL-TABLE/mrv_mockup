## 1. 시스템 개요 및 트랙 구분

### 용어 정의

| 화면 표시 용어 | 내부 관리 용어 | 설명 |
|---|---|---|
| 고지서 기반 탄소회계 | MRV 트랙 | OCR 문서 기반, 결과확인서·보고서 발급 가능 |
| 추정치 기반 탄소발자국 계산 | 계산기 트랙 | 수동 입력 기반, 문서 발급 불가 |
| Cradle-to-Gate | C2Gate | 제조전 + 제조단계까지 |
| Cradle-to-Grave | C2Grave | C2Gate + 사용 + 폐기단계 포함 |

### 트랙 분기 기준

| 구분 | 고지서 기반 탄소회계 (MRV 트랙) | 추정치 기반 탄소발자국 계산 (계산기 트랙) |
|---|---|---|
| 분기 기준 | 주요 1차 데이터 보유 (농장·수송·전력 실측값) | 1차 데이터 미보유 |
| 입력 방식 | OCR 인보이스·고지서 업로드 | 수동 폼 입력 |
| 산출 기반 | 1차 데이터 기반 산출 | 문헌값(일반데이터) 적용 |
| 발급 문서 | 결과확인서 + 결과보고서 | 화면 수치 확인만 가능 (문서 발급 불가) |
| 제3자 검증 | 외부 검증기관 수검 가능 | 불가 |
| 출력 명시 | — | "참고용, 인증 불가" 자동 명시 |

> **중요**: 시스템이 발급하는 문서는 "검증을 위한 입력 자료"이지 "검증 완료 확인서"가 아님.  
> 실제 제3자 검증은 외부 검증기관이 별도 수행.  
> 결과확인서·보고서 상단에 "외부 검증 필요" 워터마크 자동 표시 필요.

### OCR 데이터 처리 원칙

- OCR로 추출된 데이터는 사용자가 직접 수정할 수 없음.
- 확정 전: OCR 대상 파일 재업로드·변경 가능.
- 확정 후: 파일 및 OCR 추출 데이터 변경 불가. 오류 발생 시 시스템 관리자 문의.
- 확정 버튼은 MRV 트랙 검토단계 최하단에 위치. 오류 0건 확인 후 활성화.

## 2. 개발 단계 구성

### 단계별 범위

| 단계 | 트랙 | 시스템 경계 | 주요 내용 |
|---|---|---|---|
| 1단계 | MRV | C2Gate (ISO 14067) | OCR 기반 제조전·제조단계 |
| 2단계 | MRV | C2Grave (ISO 14067) | 1단계 + 제품유통·사용·폐기단계 |
| 3단계 | MRV | C2Grave (환경성적표지) | 제조전·제조·제품유통·폐기단계 (사용단계 제외) |
| 4단계 | 계산기 | C2Gate / C2Grave | 수동 입력 기반 전 구간 |

### 단계별 화면 흐름 (12단계 메뉴 구조)

① 프로젝트 기본정보
② OCR 문서 업로드
③ 제조전단계-원부자재
④ 제조전단계-수송
⑤ 누적질량기여도
⑥ 제조단계
⑦ 제품유통
⑧ 폐기단계-처리
⑨ 검토단계 → [확정]
⑩ 결과
```

**MRV ISO C2Gate**
```
① 프로젝트 기본정보
② OCR 문서 업로드
③ 제조전단계-원부자재
④ 제조전단계-수송
⑤ 누적질량기여도
⑥ 제조단계
⑦ 폐기단계-수송
⑧ 폐기단계-처리
⑨ 검토단계 → [확정]

```

**MRV ISO C2Grave**
```
① 프로젝트 기본정보

④ 제조전단계-수송

⑪ 검토단계 → [확정]

```

**계산기 C2Gate**
```
① 프로젝트 기본정보
② 제조전단계-원부자재

**계산기 C2Grave**

## 3. 데이터 입력 프로세스 플로우

### MRV 트랙 입력 플로우

```
1. 프로젝트 기본정보 등록
   ├─ 사업장 정보 (회원가입 연동, 자동 표시)
   ├─ 산정 유형 선택: MRV / 계산기
   ├─ 방법론 선택: ISO 14067 / 환경성적표지 (단일 선택)
   ├─ 시스템 경계 선택: C2Gate / C2Grave (ISO 14067만 선택 가능. 환경성적표지는 C2Grave 고정)
   ├─ 작성 방식 (C2Grave만): Option A (신규 작성) / Option B (C2Gate 연동)
   ├─ 기능단위: "로스팅된 커피" 고정 + N 입력(기본값 1) + "kg" 고정. 생성 후 변경 불가.
   ├─ 블렌딩 여부 + 블렌딩 비율 (Y 시)
   ├─ 로스터기 연료 유형: 전력 전용 / 전력+가스
   └─ 사용단계 시나리오 (C2Grave만): 드립 / 에스프레소 / 콜드브루. 생성 후 변경 불가.

2. OCR 문서 업로드 (MRV 전용)
   ├─ 생두 INVOICE (필수)
   ├─ 농장 탄소배출 증빙문서 (선택)
   ├─ B/L 또는 항공화물운송장 (선택)
   ├─ 수출국 내륙수송 거래명세서 (선택)
   ├─ 수입국 내륙수송 거래명세서 (선택)
   ├─ 최소포장재 구매 거래명세서 (선택)
   ├─ 출하포장재 구매 거래명세서 (선택, 환경성적표지 C2Grave만)
   ├─ 부자재 구매 거래명세서-여과지 (선택, 드립 C2Grave만)
   ├─ 생두 포대 무게 증빙 사진 (선택)
   ├─ 전력 고지서 (필수)
   ├─ 가스 고지서 (선택, 전력+가스 시)
   ├─ 재생에너지 설치 확인서 (선택)
   ├─ 재생에너지 발전량 모니터링 기록 (선택)
   ├─ 납품 거래명세서 (선택, C2Grave만)
   └─ 재활용폐기물처리 증빙서류 (선택, C2Grave만)
   → OCR 백그라운드 실행. 결과 임시 풀 보관.

3. 제조전단계-원부자재
   ├─ 농장 탄소배출 증빙 선택(풀) → OCR 추출 또는 문헌값 1.165 자동 적용
   ├─ dLUC 배출량·흡수량(증빙 내 구분 기재분) → OCR 추출, 결과·보고서 표시 전용(농장 탄소배출량에 이미 포함, 별도 합산 금지)
   ├─ 생두 INVOICE 선택(풀) → OCR 추출
   ├─ 생두 투입량: 역산 자동 (생산량 × 블렌딩비율 ÷ 0.7612)
   ├─ 생두 포대 무게: 포대 사진 OCR 또는 기본값 자동 (황마 1,000g / PP 300g)
   ├─ 최소포장재: 경로 A/B/C 선택. DB 매핑 수행.
   ├─ 출하포장재: 박스·테이프 (환경성적표지 C2Grave만)
   └─ 여과지 (드립 C2Grave만)

4. 제조전단계-수송
   ├─ 생두 수송 3구간 (수출국내륙·국제·수입국내륙). N개 Leg 등록.
   └─ 부자재 수송 (최소포장재·출하포장재·여과지 공급처별 자동 생성)

5. 누적질량기여도
   └─ 전 투입물 DB 매핑 완료 후 자동 분석 (컷오프 없음 100%)

6. 제조단계
   ├─ 전력 고지서 선택(풀) → OCR. 전력 배출량 자동 산출.
   ├─ 재생에너지 직접 생산 여부 → Y 시: 설치 확인서 + 발전량 기록 선택(풀) → OCR.
   ├─ 가스 고지서 선택(풀) → OCR (전력+가스 시)
   └─ 채프 발생량 자동 산출 (생두 투입량 × 0.0057)

[환경성적표지·ISO C2Grave 선택 시]
7. 제품유통
   ├─ 납품 거래명세서 선택(풀) → 납품처명·주소 OCR
   └─ 수송 거리 API 자동산출 (로스터리→납품처)

[ISO C2Grave 선택 시]
8. 사용단계
   └─ 분쇄·추출 배출량 문헌값 자동 산출 (사용자 입력 없음)

[ISO C2Gate·C2Grave 선택 시]
9. 폐기단계-수송
   └─ 처리방식별(소각·매립·재활용) 시설 각각 자동 매핑 → 거리 API 자동산출

10. 폐기단계-처리
    ├─ 폐기물 발생량 전 단계 자동 누적값 표시
    ├─ 재활용 위탁처리 증빙서류 선택(풀) → OCR (MRV 트랙)
    │   └─ 품목별 독립 처리. 발생량 상한 적용. 재활용 증빙분 처리 EF = 0.
    └─ 국가 통계 비율 자동 적용 (잔여량)

11. 검토단계
    └─ 24개 검증 항목 자동 정합성 검토

12. [확정] (검토단계 최하단)
    ├─ 오류 0건 + 경고 항목 전체 확인 체크 시 활성화
    ├─ 확정 전: 파일 재업로드·변경 가능
    └─ 확정 후: 파일 및 OCR 추출 데이터 변경 불가. 해시체인(SHA-256) 무결성 보장.

13. 결과 및 보고서 발행
    └─ 결과확인서 + 결과보고서 PDF 발급. EF 스냅샷 고정 저장.
```

### 계산기 트랙 입력 플로우

```
1. 프로젝트 기본정보 등록
   ├─ 산정 유형: 계산기
   ├─ 방법론: ISO 14067 (환경성적표지 계산기 미지원)
   ├─ 시스템 경계: C2Gate / C2Grave
   └─ 생성 후 변경 불가

2. 제조전단계-원부자재
   └─ 사용자 직접 입력 (OCR 없음. 생두명·생산국·최소포장재 종류 입력.)

3. 제조전단계-수송
   └─ 거리(km) + 수송수단 직접 입력 (3구간)

4. 제조단계
   ├─ 배치당 생두 투입량·소비전력·사용시간 직접 입력
   └─ 추정 전력·가스 사용량 자동 계산

[C2Grave 선택 시]
5. 사용단계
   └─ 추출 시나리오 선택 → 배출량 문헌값 자동 산출

6. 폐기단계-처리
   └─ 국가 통계 비율 자동 적용. 사용자 입력 없음.

7. 결과 확인 (문서 발급 불가, "참고용·인증 불가" 자동 명시)
```

## 4. 계층 구조: 회원-프로젝트

```
회원 (로스터리)
└─ 프로젝트 [1:N]
   └─ 데이터 항목 [1:N]
      └─ 산출 결과
```

> v2 대비 변경: 배치(Batch) 단위 제거. 프로젝트 단위로 연간 집계 처리.

### 프로젝트 단위 정의

- "산정 유형 × 시스템 경계 × 기준년도" 조합으로 구분
- 동일 원두라도 C2Gate 버전과 C2Grave 버전은 별도 프로젝트
- 표준 선택, 트랙(MRV/계산기) 선택, 시스템 경계는 프로젝트 생성 시 확정, 이후 변경 불가

### 공유 데이터 (프로젝트 간 재사용 가능)

| 항목 | 재사용 가능 여부 | 비고 |
|---|---|---|
| 생두 원단위 탄소발자국 | 가능 | 연도별 버전 관리 필요 |

## 6. 시스템 경계 설정

### 기능단위 및 산정 구조

> **기능단위: 로스팅된 커피 1 kg (시설 단위 기간 평균 원단위)**

```
단위 기간 총 배출량 (kg CO₂e)
─────────────────────────── = 평균 CFP (kg CO₂e / kg 원두)
단위 기간 총 원두 생산량 (kg)
```

- 제품별 CFP가 아닌 생산시설 평균값 (average intensity CFP)
- 보고서 자동 명시: "본 결과는 개별 제품 단위 CFP가 아닌 생산시설 단위 기간 평균 원단위 기준으로 산정된 값임"
- 시설 전체 경계 (머신별 분리 측정 없음) → ISO 14067 §6.3.4 허용 범위

### 방법론별 시스템 경계

| 방법론 | 시스템 경계 | 사용단계 | 폐기 수송 | 비고 |
|---|---|---|---|---|
| ISO 14067 C2Gate | 제조전 + 제조 + 제조공정 폐기물 | 제외 | 제조공정 폐기물 수송 포함 | 부분 CFP |
| ISO 14067 C2Grave | 전 과정 | 포함 | 포함 | — |
| 환경성적표지 | 제조전 + 제조 + 제품유통 + 폐기 | 제외 | 미포함 | 비내구재 규정 §4.2.1.2.3 |

### 단계별 경계

| 단계 | 경계 설정 | 적용 범위 |
|---|---|---|
| 생두 재배·가공 | 시스템 경계 포함. 농장 직접 통제 공정 아님 | 농장 CFP 인증값 인용. 없을 시 문헌값 적용 |
| 생두 수송 3구간 | 시스템 경계 내 (Scope 3 업스트림) | 전 트랙·전 경계 공통 |
| 로스팅 | 시스템 경계 내 핵심 | 전 트랙·전 경계 공통 |
| 제품유통 (출고 수송) | 시스템 경계 내 | 환경성적표지·ISO C2Grave |
| 사용단계 | 시스템 경계 내 | ISO C2Grave만 |
| 폐기 수송 | 시스템 경계 내 | MRV ISO 트랙만 |
| 폐기 처리 | 시스템 경계 내 | 전 트랙·전 경계 공통 |

### 생두 재배·가공 CFP 인용 처리

- **ISO 14067**: §6.3.5 기준, 로스터리가 직접 통제하지 않는 공정에 대해 2차 데이터·문헌값 사용 허용
- **시스템 처리**: 생두 재배·가공 단계는 시스템 경계에 포함됨. 로스터리에서 농장의 1차 데이터를 직접 확보하는 것이 현실적으로 불가능하므로, 농장이 제공하는 CFP 인증값을 OCR로 입력하여 인용 산정함. 농장 CFP 증빙이 없는 경우 문헌값(Nab & Maslin 2020, 1.165 kg CO₂e/kg GB)을 적용함.
- 보고서 명시: "생두 재배·가공 단계는 시스템 경계에 포함됨. 농장이 제공한 CFP 인증값을 인용하여 산정함 / 농장 CFP 미확보로 문헌값(Nab & Maslin 2020, 1.165 kg CO₂e/kg GB)을 적용함."

### dLUC(직접 토지이용변화) 처리

| 구분 | ISO 14067 | 환경성적표지 |
|---|---|---|
| 근거 | §6.4.9.5 dLUC 반영·문서화 요구 | 별도 조항 없음 |
| 문헌값(1.165) 적용 시 | Nab & Maslin(2020)이 조사 대상 농지 20년 이상 무변화 가정으로 dLUC 배제 → §6.4.9.5 비고1(IPCC Tier 1 20년 기준)과 부합 → dLUC=0 간주 | 별도 산정하지 않음(단순 미반영) |
| 농장 CFP 적용 시 | dLUC 배출량·흡수량(증빙 내 구분 기재분)을 OCR로 추출, 결과·보고서에 표시 전용으로 병기. 정보 미확인 시 "본 CFP가 ISO 14067 §6.4.9.5의 dLUC 요건을 충족하는지 여부는 불확실하다" 자동 기재 | 해당 없음 |

> ⚠️ dLUC 배출량·흡수량 필드는 "농장 탄소배출량"에 이미 포함된 하위 구성요소를 표시하기 위한 값으로, 생두 단위 탄소배출량 산정 시 별도로 더하거나 빼지 않음(표시 전용, 이중합산 금지).

| 농장 내 이동 | 농장 CFP에 포함 산정 | 농장 CFP에 포함 |
| 수출국 내륙수송 | 로스터리 | Scope 3 업스트림 |
| 국제 해상수송 | 로스터리 | Scope 3 업스트림 |
| 수입 국내수송 | 로스터리 | Scope 3 업스트림 |

> 수출국 내륙수송부터 로스터리 부담으로 고정.

입력 방식에 따라 등급 자동 부여 → 보고서 방법론 섹션 자동 출력

### 고지서 발급월 기준 검증

- 안분 미적용. 고지서 발급월 기준 사용량 전체 적용.
- 검토단계 자동 검증: 고지서 발급월 ↔ 프로젝트 수집 기간 포함 여부. 기간 외 감지 시 경고 (허용은 됨).
- 보고서 각주 자동 삽입: "고지서 발급월 기준 사용량 적용. 청구 기간 내 일별 사용량 안분 미적용"

### LUC 처리

- 삭제 확정 (2026.06.23). 프로젝트 내 LUC 입력·표시 없음.
- 보고서 한계사항 자동 기재: "토지이용변화(LUC) 관련 데이터는 수집되지 않아 본 산정에서 제외함."

### 바이오제닉 탄소 처리

- 로스팅은 원두(바이오매스) 자체를 연소시키는 공정이 아닌 가스(화석연료) 열원에 의한 가열 공정으로, ISO 14067 §6.4.3.3·환경성적표지 부속서 E.5 어느 쪽도 적용대상 자체가 아님(양 표준 공통 결론).
- 채프·커피박 등 폐기단계에서 발생하는 바이오제닉 CO₂는 탄소중립 원칙에 따라 배출량 계산에 미포함하며, 비이산화탄소(CH₄ 등)는 현재 적용 중인 폐기물 처리 배출계수(emission_factors.md F-3)의 산정값에 이미 포함되어 있음(ILCD 형식 배경 LCI 데이터 검증 완료, Climate change = Biogenic+Fossil+LULUC 검산 일치).
- 결과: 별도의 바이오제닉 탄소 산정 대상 자체가 없으므로 미결 항목에서도 제외됨(§14 참조).

```
결과 출력 형태:
화석 기반 CFP:   X.XX kg CO₂e / kg RC  ← 메인 수치
* 바이오제닉 탄소는 CFP 합산에 포함되지 않음 (한계사항 명시)
```

| **Scope 1** | 가스 로스터기 직접 연소, 에프터버너 가스 연소 | 가스 전용·혼합 로스터리만 해당 |
| **Scope 2** | 로스팅 구매 전력, 제연기·에프터버너 전력 | 시설 전체 고지서 기반. 재생에너지 자가발전분 배출계수 0 적용 |
| **Scope 3 업스트림** | 생두 수송 3구간, 농장 CFP 인용값 (Cat.1), 포장재 생산 | 제조전단계 전 구간 |
| **Scope 3 다운스트림** | 제품유통, 사용(분쇄·추출), 폐기(수송·처리) | ISO C2Grave·환경성적표지 해당 단계별 상이 |

- 전 방법론 공통으로 참고용 Scope 1/2/3 분류 표시. 결과 화면 항상 표기.

### 로스터기 연료 유형에 따른 Scope 분류

```
가스+전기 혼합 → Scope 1 (가스 직접연소) + Scope 2 (전력)
전기 전용     → Scope 2만 해당
```

### 제연기·에프터버너 Scope 분류

```
제연기   → 전력 사용만 → Scope 2
에프터버너 → 전력 사용 → Scope 2
           가스 연소  → Scope 1
```

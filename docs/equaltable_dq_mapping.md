# Equaltable 활동 데이터 품질 매핑 테이블

> 작성 기준: 2026년 7월 29일
> 목적: data_fields 항목별 입력 유형 → 품질 패턴 매핑 (개발자 참조용)
> 기준 문서: equaltable_6월_신규설계.md / equaltable_data_fields.md
> 참조 기준: equaltable_emission_factors.md A-4 (데이터 품질 평가 기준)
> 현재 버전: v2.0.4
> 이전 버전: v2.0.3
>
> 범례: T=기술적 대표성 / G=지리적 대표성 / Te=시간적 대표성 / P=정밀성 / C=완전성 / Co=일관성
> 점수: 1(매우 낮음) ~ 5(매우 높음) / 상속 = 상위 입력값 품질 자동 상속
> ⚠️ 본 문서(별첨3)는 활동데이터 입력방식에 따른 품질(A-5 기준)이며, 배출계수 자체의 출처 품질(A-4 기준, 별첨1)과는
> 별개 지표임. 화면·결과보고서에는 두 지표를 항목별로 병기 표시하며, 별도의 요약 신뢰도(단일 등급)는 산출하지 않는다.


### 환경성적표지-데이터 품질 등급 (자동 분류)

| 등급 | 조건 |
|---|---|
| **측정치** | OCR 문서 기반 1차 데이터. 직접 입력 실측값 |
| **계산치** | 측정값 기반 시스템 자동 계산. 역산 투입량 |
| **추정치** | 통계·가정·모델·문헌 기반 간접 산출. DB 자동 적용. 국가 통계. API 거리 산출 |

입력 방식에 따라 등급 자동 부여 → 보고서 방법론 섹션 자동 출력
